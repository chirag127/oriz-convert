oriz Convert

Universal converter — CSV / JSON / YAML / XML, units, number bases, and color formats. This is the about page for the project. The live tool runs at convert.oriz.in.

Open the live app → Source code llms.txt

What it is

A free, single-purpose converter that transmutes structured data between CSV, JSON, YAML, and XML; converts physical units; converts number bases; and converts color formats. Everything happens in your browser — paste text or drop a file, copy or download the result.

Key features

  • Data formats — CSV ⇌ JSON ⇌ YAML ⇌ XML, any direction; drag-drop a file or paste.
  • Units — length, mass, temperature, and data size; one value converts to every unit at once.
  • Number bases — binary / octal / decimal / hex / base-2..36, arbitrary precision (BigInt), 0x/0b/0o prefixes.
  • Color — HEX ⇌ RGB ⇌ HSL with alpha, live swatch, native picker.
  • Optional AI — describe a dataset or infer a JSON Schema; keyless, degrades gracefully.

Tech

  • Client-only Astro static site with React 19 islands.
  • Optional AI via @chirag127/oz-ai (g4f multi-provider failover, no API key).
  • PWA-installable with offline support.
  • 100% in-browser — no upload, no signup, nothing stored.

This page is intentionally plain — it is not the app. It describes the project and links to the live tool. For LLMs and agents, machine-readable summaries live at /llms.txt and /llms-full.txt.
